# Telegram Chat Activity Bot

Бот для статистики групповых чатов и лёгких развлечений. Python 3.11+, aiogram 3, SQLite.

## Команды статистики
- `/top` — топ за всё время сбора
- `/topday` — топ за сегодня
- `/topweek` — топ за последние 7 дней
- `/me` — личная статистика и место в рейтинге
- `/stats` — общая статистика чата
- `/activity` — активность по часам за сегодня
- `/achievements` — достижения по количеству сообщений

## Развлекательные команды
- `/title` — случайный титул
- `/coin` — монетка
- `/dice` — кубик
- `/ball получится ли?` — ответ магического шара
- `/choose чай | кофе` — выбрать из вариантов
- `/fortune` — случайное предсказание
- `/roast` — безобидная случайная подколка; можно ответить на сообщение
- `/ship` — случайная шуточная совместимость; можно ответить на сообщение для выбора второго участника
- `/duel` — ответь на сообщение другого участника командой, чтобы сравнить число сообщений

## Установка на Windows CMD

1. Установи Python 3.11 или новее.
2. Создай бота через `@BotFather` командой `/newbot`.
3. Создай `.env` на основе `.env.example`, впиши токен в `BOT_TOKEN`.
4. Открой CMD в папке проекта и выполни по одной строке:

   ```cmd
   py -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe main.py
   ```

   Можно задать токен только на время текущего окна CMD вместо файла `.env`:
   `set BOT_TOKEN=ТВОЙ_ТОКЕН`
   затем запустить ` .venv\Scripts\python.exe main.py`.

## Настройка Telegram

Добавь бота в группу. Чтобы он видел обычные сообщения, открой `@BotFather` → `/mybots` → выбери бота → `Bot Settings` → `Group Privacy` → `Turn off`, затем удали бота из группы и добавь снова.

## Ограничения и приватность

- Бот считает сообщения только с момента, когда он добавлен и получает обновления; историю публичного чата задним числом Bot API не выдаёт.
- Бот не сохраняет текст сообщений — только счётчики активности и имя/username для рейтинга.
- Часовой пояс берётся из системы, на которой запущен бот.
- `/ship` — исключительно случайная шутка, а не реальная оценка отношений или совместимости.
- Не публикуй токен и не загружай `.env` в GitHub.
- Для постоянной работы программа должна оставаться запущенной на компьютере или сервере.
